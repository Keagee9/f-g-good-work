# **App Name**: AcuClone

## Core Features:

- Service Listings: Display available services (cloned from the provided site) with descriptions and prices.
- Calendar Display: Show the appointment calendar, highlighting available slots (pulled from the service page to simulate availability).
- Time Slot Selection: Allow users to select available time slots.
- Styling Suggestor Tool: Uses a generative AI tool that reasons about the uploaded photo, analyzes the image and suggests braid styles, powered by Next.js.
- Confirmation Display: Display a confirmation screen after 'selection'.

## Style Guidelines:

- Primary color: Saturated orange (#E67E22), reflecting the 'Bob Braids' service.
- Background color: Very dark grayish-orange (#26221E), providing a dark theme foundation.
- Accent color: Pale yellow-orange (#FAD7A0), used to highlight key elements.
- Font: 'Inter', a grotesque sans-serif for body and headlines.
- Minimalist icons for services and time slots, maintaining clarity.
- Grid-based layout for service listings and calendar display.
- Subtle transition animations on interactions for a smooth user experience.
